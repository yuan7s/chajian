# 外部程序 — 操作文档

## 概述

VB.NET Windows Forms 应用（.NET Framework 4.8），作为 **SolidWorks 插件**运行。通过状态栏下拉框选择目标 SW 实例，提供文件格式转换、属性管理、设计树排序、重命名、编码整理等功能。

---

## 启动与生命周期

- `Application.Designer.vb`：`ShutDownStyle = AfterAllFormsClose`，所有窗体关闭后才退出
- 启动时自动刷新 SW 进程列表，优先恢复上次选择的实例（`My.Settings.DefaultSwProcessId`）
- 通过 ROT（Running Object Table）枚举 `SldWorks.Application` 查找并绑定所选 PID 的 SW COM 实例

### SW 连接机制

```
用户选择下拉项
  → swProcessCombo_SelectedIndexChanged
  → 保存 ProcessId 到 My.Settings
  → ConnectToSelectedSw()
    → FindSwAppByPid(pid)     ' ROT 枚举，按 PID + 标题匹配
    → 回退 GetActiveObject()  ' 兜底，校验 PID
  → AttachDocEvents()         ' 绑定 ActiveDoc/NewSelectionNotify
  → UpdateStatusBar()
```

`GetSelectedSwApp()` 为所有按钮提供选中的 SW 实例，确保操作目标一致。

## Form3 — 重命名工具

```
┌─────────────────────────────────────────────┐
│ 旧命名: [原文件名（只读）]                   │
│ 新命名: [输入新名称]                         │
│                                              │
│ [重命名] [取消]  ☑带图改名 ☑下料尺寸        │
│ ☑版本 [A]  ☑设计&出图 [    ]               │
│                                              │
│ 存在工程图: ● 绿色 / ● 红色                 │
│ 命名已存在: 重名(装配体+本地)                │
└─────────────────────────────────────────────┘
```

### 重命名流程
1. 获取目标文档（优先选中组件，默认活动文档）
2. 生成新路径 → `SaveAs3`
3. 写入自定义属性：文件名称、物料编码、零件图号
4. 可选：版本、设计/出图、下料尺寸
5. 可选：同步复制/替换工程图文件（带图改名）
6. 删除源文件

### 重名检查（防抖 500ms）
- 本地：`File.Exists(新路径)`
- 装配体：`FeatureManager.GetFeatures(True)` 批量构建 `HashSet`，O(1) 查找
- 缓存随文档切换失效

## Form4 — 编码整理

```
┌───────────────────────────┐
│ 名称筛选（可选）          │
│ [____________]            │
│                           │
│ 处理范围                  │
│ ☑处理装配体  ☑处理零件   │
│                           │
│ 排除条件                  │
│ ☑排除虚拟装配体           │
│ ☑排除标准件               │
│ ☑排除外购件               │
│                           │
│ [执行编码整理]             │
└───────────────────────────┘
```

### 功能流程
1. 遍历装配体所有组件（递归子装配体）
2. 按名称筛选、类型筛选、排除条件过滤
3. 对每个符合条件的组件同步文件名到自定义属性（物料编码、零件图号、文件名称）
4. 标准件判断：`零件类型 Contains "标准件"`（包含匹配）
5. 外购件判断：`零件类型 Contains "外购"`
