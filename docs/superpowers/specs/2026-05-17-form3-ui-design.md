# Form3 界面优化设计

## 目标

整理 Form3（重命名窗口）底部按钮、复选框和输入框的对齐布局，简化名称冲突提示文本。

## 当前问题

- Button1 和 Button2 位置与复选框行不对齐
- 复选框列间距不均匀（x=453 和 x=575），版本输入框过窄（38px）
- Label6 文本过长，超出窗口空间

## 设计变更

### 1. 底部布局重新对齐

```
[Button1]  [重命名]     ☑带图改名    ☑版本 [A____]
                       ☑下料尺寸    ☑设计&出图 [________]
```

- 两个按钮左对齐，顶部与复选框第一行（"带图改名"/"版本"）对齐
- 复选框两列：左列"带图改名"/"下料尺寸"，右列"版本"/"设计&出图"
- TextBox3（版本输入）加宽至约 60px
- TextBox4（设计&出图输入）加宽至约 80px
- 输入框紧贴对应复选框右侧

### 2. Label6 文本简化

| 当前 | 简化后 |
|------|--------|
| `装配体及本地均存在同名文件` | `重名(装配体+本地)` |
| `装配体中存在同名文件` | `重名(装配体)` |
| `本地存在同名文件` | `重名(本地)` |
| `可以保存` | `可保存` |
| `可以保存，存在工程图` | `可保存，有工程图` |

### 3. 保留不变

- 窗口大小、标题、FixedDialog 样式
- 上半部分（旧命名/新命名行、TextBox1/TextBox2、Label3/Label4/Label5）
- Button1 保持不变（不修改其功能）
- Button2 保持不变
- 所有现有功能逻辑不变

### 不在范围

- Form1 或 Form2 的界面改动
- Form3 功能逻辑变更
- 拖拽移动功能不改动
